# 🛡️ EmailSentinel

## Monitor Top Email Senders and Receivers

EmailSentinel is an Information and Cyber Security micro-project developed to monitor and analyze email communication patterns.

---

## 🎯 Project Objective

The main objective of EmailSentinel is to monitor email communication and identify the top email senders and receivers.

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- CSV
- Visual Studio Code

---

## 📊 Features

- Monitor top email senders
- Monitor top email receivers
- Analyze sender-receiver communication
- View email activity over time
- Identify high-volume email activity
- Upload CSV email datasets
- Basic cybersecurity risk assessment

---

## ⚙️ Installation

### 1. Clone the repository

    git clone https://github.com/YOUR-USERNAME/EmailSentinel.git

### 2. Move into the project directory

    cd EmailSentinel

### 3. Create a virtual environment

    python -m venv venv

### 4. Activate the virtual environment on Windows

    venv\Scripts\activate

### 5. Install the required packages

    pip install streamlit pandas

---

## ▶️ Running the Project

Start the application with:

    streamlit run app.py

The EmailSentinel dashboard will open in your web browser.

---

## 🔐 Cybersecurity Relevance

Email monitoring can help identify unusual communication patterns and high-volume email activity that may require further investigation.

The project provides basic monitoring indicators that can assist in identifying potentially unusual email activity.
